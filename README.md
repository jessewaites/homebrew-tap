# Jesse Waites's Homebrew tap

Install CipherLab, an opinionated workspace for cipher research with AI coding agents:

```sh
brew install jessewaites/tap/cipherlab
cipherlab new my-cipher
```

Updates:

```sh
brew update
brew upgrade cipherlab
```

The formula builds a checksummed release source archive using Homebrew's Go build dependency. It supports macOS and Linux. New stable CipherLab releases update this tap automatically.

Source, documentation, and downloadable executables: [jessewaites/cipherlab](https://github.com/jessewaites/cipherlab).
